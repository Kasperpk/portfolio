Another mechanism with which information creates value is that it can help systems learn over time. Monitoring important metrics of the system and displaying it allows feedback loops to play it's part in improving the overall functioning of the system over time by guiding behaviors towards more productive ones.

In addition to the mechanisms that describe the value proposition of data there are some variables which compound the value of data and of building knowledge and data-centric factories. The first one is that technology is simply getting more powerful. The ways in which raw data material can be generated, stored and activated continuously expands and recently it has created a range of new opportunities. Secondly the accumulation of data over time and from different sources creates a multiplier effect that increases the value of individual pieces. 

Together these arguments help understand and justify the investments that management teams are making in digital infrastructure and data systems that becomes the basis for leveraging this "*new oil*" as it has been called.
